# Architecture

### Backend Request Lifecycle

```mermaid
flowchart LR
    A[Client] --> B[Route]
    B --> C[Middleware]
    C --> D[Controller]
    D --> E[Validation]
    E --> F[Service]
    F --> G[Repository]
    G --> H[(Database)]
    H --> G
    G --> F
    F --> I[Resource]
    I --> J[JSON Response]
```
